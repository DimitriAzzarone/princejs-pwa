# Prince of Persia – PWA privata

Questa cartella contiene la versione installabile del gioco.

## Pubblicazione con GitHub Pages

1. Caricare tutti i file nella radice del repository.
2. Aprire **Settings → Pages**.
3. Scegliere **Deploy from a branch**.
4. Selezionare il branch `main` e la cartella `/ (root)`.
5. Aprire il collegamento HTTPS fornito da GitHub Pages.
6. Sul telefono usare **Aggiungi a schermata Home**.

Dopo il primo caricamento completo, l’app può funzionare offline.
